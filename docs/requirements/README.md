# Requirements

Salsa's requirements are captured by 14 December 2026.

Each requirement names its source (a EuRoC rule, another board's interface, or
a stated need), the mechanism that meets it, and how it is verified. Once
frozen, a requirement changes only through a row in
[decisions.md](../../decisions.md).

| ID | Requirement | Source | Mechanism | Verification | State |
| --- | --- | --- | --- | --- | --- |

See [Burrito's requirements](https://github.com/ULAS-HiPR/Ogma2/blob/main/docs/requirements/burrito.md) for a worked
example, and the [rules sweep](https://github.com/ULAS-HiPR/Ogma2/blob/main/docs/requirements/2026-11-21-rules-sweep.md)
for EuRoC SRD 1.1 and IREC 2027 against the core.
